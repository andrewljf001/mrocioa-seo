## 二、核心功能清单

| 功能 | 描述 |
|------|------|
| 8K/4K支持 | 8K@60Hz / 4K@120Hz / HDMI 2.1 |
| HDCP跨版本兼容 | 支持不同HDCP版本设备混接（PS5+PS4+Switch等）不丢失信号 |
| ARC/eARC全通道音频 | 借助电视ARC/eARC，所有通道设备均可输出音频到音箱，非仅PORT1 |
| EDID编辑（MODE键） | 一键强制切换输出分辨率（8K→4K@60Hz→1080P），解决兼容性问题 |
| 通用CEC遥控器 | 单个遥控器控制周边大部分设备，替代AppleTV/FireTV遥控，调节音箱音量 |
| 苹果iOS APP | 实现遥控器所有功能，显示每个通道设备名称与图标 |
| AUTO/手动切换开关 | 用户可自主开关自动切换功能 |
| 随电视升级 | ARC/eARC能力随用户电视升级自动提升，产品长期有效 |

## 三、真正能转化的核心痛点

经过分析，所有功能中**只有两个**具备真正的高转化力：

### 痛点一：HDCP兼容问题（转化力：极高）

**买家真实场景：**
```
家里有PS5 + PS4 + Nintendo Switch混接在同一个切换器
切换到PS4/Switch后再切回PS5
PS5没有画面输出，一脸懵
去Google/Reddit搜索解决方案
```

**为什么高转化：**
- 这是Amazon上HDMI Switch差评最集中的问题
- 买家已经被折磨过，需求极其迫切
- 愿意付$80立刻解决
- 大量Reddit/论坛帖子在讨论这个问题

**对应搜索词：**
- PS5 no signal after HDMI switch
- PS5 loses signal when switching back
- HDMI switch HDCP compatibility issue
- PS5 PS4 HDMI switch not working

---

### 痛点二：ARC全通道音频问题（转化力：极高 + 唯一解决方案）

**买家真实场景：**
```
买了音箱，用ARC接电视
接了HDMI切换器后
切换到其他设备，音箱没有声音了
或者只有PORT1能用音箱，其他口都没声
```

**为什么高转化：**
- 市面上其他切换器的ARC要么只支持PORT1，要么需要音频提取器
- Mrocioa是目前**唯一**通过电视ARC/eARC实现全通道音频的切换器
- 无竞品 = 找到这个解决方案的人几乎100%会购买
- 随用户电视升级自动升级，长期价值高

**对应搜索词：**
- HDMI switch all ports audio soundbar
- HDMI switch ARC not working other ports
- Soundbar stops working when switching HDMI
- HDMI switch eARC every input
